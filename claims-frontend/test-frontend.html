🚀 Claims Frontend Test Page

Test the React frontend application for submitting insurance claims

1. Start the Backend Server

First, make sure the Veramo backend server is running:

cd veramo-server
npm start

2. Start the Frontend Development Server

In a new terminal, start the React frontend:

cd claims-frontend
npm run dev

The application will be available at http://localhost:3001

3. Test the Application

Follow these steps to test the claim submission:

  1. Open http://localhost:3001
  2. Connect your MetaMask wallet
  3. Switch to Hardhat local network (Chain ID: 1337)
  4. Fill out the claim form with test data
  5. Submit the claim and watch the progress

5. Expected Flow

The application should:

  • ✅ Verify the insurance credential with the backend
  • ✅ Upload the PDF file and compute SHA-256 hash
  • ✅ Submit the claim to the smart contract via MetaMask
  • ✅ Display success message with transaction details

6. Troubleshooting

If you encounter issues:

  • Check browser console for error messages
  • Ensure MetaMask is connected and on correct network
  • Verify backend server is running and accessible
  • Check that the Claims contract is deployed
